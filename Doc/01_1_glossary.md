| Symbol             | Name                       | Meaning                                                                                                                                                                          | Formula / typical value                                                          |
| ------------------ | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| c                  | speed of light             |                                                                                                                                                                                  | 3·10⁸ m/s                                                                        |
| f, f_c             | carrier / centre frequency | The RF frequency at which the radar transmits                                                                                                                                    | 76–81 GHz                                                                        |
| λ                  | wavelength                 | Length of one RF wave. Sets the phase sensitivity.                                                                                                                               | λ = c/f ≈ 3.9 mm at 77 GHz                                                       |
| S                  | slope                      | How fast the chirp frequency rises                                                                                                                                               | MHz/µs, e.g. 80 MHz/µs                                                           |
| T_c                | chirp duration             | Length of one chirp (ramp + idle time)                                                                                                                                           | e.g. 57 µs                                                                       |
| B                  | bandwidth                  | Total frequency span swept during the sampled part of one chirp                                                                                                                  | B = S · T_ADC (sampling time)                                                    |
| B_max              | maximum bandwidth          | The largest B the chip allows in one sweep                                                                                                                                       | ≈ 4.5 GHz on AWR2944                                                             |
| τ                  | (group) delay              | Round-trip time from antenna to target and back                                                                                                                                  | τ = 2R/c                                                                         |
| f_b                | beat / IF frequency        | Frequency of the mixer output for a target at range R                                                                                                                            | f_b = S·τ = 2SR/c                                                                |
| IF                 | intermediate frequency     | The mixer output path (analog filter + ADC). Its bandwidth F_IF limits which f_b can be seen.                                                                                    | F_IF ≈ 15–20 MHz                                                                 |
| F_s                | ADC sample rate            | Samples per second the ADC takes from the IF signal. Msps = mega-samples per second.                                                                                             | e.g. 12.8 Msps                                                                   |
| R                  | range                      | Distance to the reflector                                                                                                                                                        | R = c·f_b/(2S)                                                                   |
| **ΔR**             | **range resolution**       | The smallest distance by which two reflectors must be separated to show up as two separate peaks. It depends **only on bandwidth**. It is also the width of one FFT "range bin". | ΔR = c/(2B). With B = 4.5 GHz this gives ≈ 3.3 cm.                               |
| **R_max**          | **maximum range**          | The farthest distance whose beat frequency still fits through the IF filter / ADC. Beyond it, targets alias or are filtered out.                                                 | R_max = F_IF·c/(2S). For real sampling, use F_IF ≤ F_s/2, so R_max = F_s·c/(4S). |
| range bin          |                            | One output point of the range FFT. Bin k corresponds to range k·ΔR.                                                                                                              | N real samples → N/2 bins                                                        |
| v                  | radial velocity            | Speed towards/away from the radar, measured from the phase change between chirps (Doppler)                                                                                       | v = λ·Δφ/(4π·T_c)                                                                |
| φ                  | phase                      | Phase of the echo in a range bin. A 1 rad change means the target moved λ/4π ≈ 0.31 mm.                                                                                          | φ = 4πR/λ                                                                        |
| chirp / frame      |                            | A **frame** is a burst of N chirps, repeated every frame period (e.g. 10 ms). Range comes from within one chirp; velocity comes from across the chirps of a frame.               |                                                                                  |
| profile / subframe |                            | A **profile** is one chirp shape (start freq, slope, samples). A **subframe** is a part of an advanced frame that uses its own profile.                                          | up to 4 each                                                                     |
